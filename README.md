# HunterHub

Find Quests. Earn Rewards.

HunterHub is a mission-based marketplace that connects quest creators with hunters.

Examples:

- Dog Walking
- IT Support
- Tutoring
- Delivery
- Elderly Care

## MVP Features

- User Registration
- Login
- User Profile
- Post Quest
- Browse Quests
- Accept Quest
- Ratings

## Future Features

- Chat System
- Payment Gateway
- Identity Verification
- Mobile App
